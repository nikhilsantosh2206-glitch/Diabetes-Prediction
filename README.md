🩺 Diabetes Prediction Web App
📌 Project Overview

This project is a Machine Learning-based Diabetes Prediction System that predicts whether a person is likely to have diabetes based on medical input parameters. The model is trained using a dataset and deployed using a Streamlit web application for easy user interaction.

🚀 Features
Predicts diabetes based on user input
Machine Learning model (Logistic Regression / other models)
Interactive web interface using Streamlit
Real-time prediction results
Easy to use and lightweight application
🧠 Tech Stack
Python 🐍
Pandas & NumPy
Scikit-learn 🤖
Streamlit 🌐
Pickle (Model Saving)

⚙️ How to Run the Project
1. Clone the repository
git clone https://github.com/your-username/diabetes-prediction.git
2. Go to project folder
cd diabetes-prediction
3. Install dependencies
pip install -r requirements.txt

If requirements.txt not available:

pip install streamlit pandas numpy scikit-learn
4. Run the application
streamlit run app.py
🌐 Output

After running, open browser:

http://localhost:8501
📊 Input Features Used
Glucose Level
Blood Pressure
BMI
Age
Insulin
Skin Thickness
🎯 Model Information
Algorithm: Logistic Regression / ML Classifier
Dataset: Pima Indians Diabetes Dataset
Output: Binary Classification (Diabetic / Non-Diabetic)
