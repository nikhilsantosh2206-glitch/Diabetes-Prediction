# 🩺 Diabetes Prediction Web Application

A Machine Learning based web application that predicts whether a person is likely to have diabetes based on various medical parameters.  
The project is developed using Python, Scikit-learn, and Streamlit to provide fast, accurate, and real-time diabetes prediction through an interactive user interface.

---

## 📌 Project Overview

The Diabetes Prediction System is designed to analyze medical input features such as glucose level, BMI, insulin, blood pressure, and age to determine the likelihood of diabetes.  
The machine learning model is trained on healthcare data and deployed as a web application using Streamlit for easy accessibility and user interaction.

---

## 🚀 Key Features

- Real-time diabetes prediction
- Interactive Streamlit web interface
- Machine Learning classification model
- Fast and lightweight application
- User-friendly medical input system
- Accurate prediction results
